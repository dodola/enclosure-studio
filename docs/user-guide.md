# 壳研使用指南

面向矩形开发板、矩形屏幕、矩形键盘及圆形面板按钮的本地外壳设计平台。支持照片上传与透视校准、圆孔候选识别、组件布局、实体三维预览和 STL 打印包导出。

## 启动

需要 Node.js 22.19+、Python 3.11+。

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r server/requirements.txt
npm install
npm run dev
```

打开 http://localhost:5176 。开发服务使用前端 5176、后端 8011 端口；Vite 代理 `/api`。

```sh
npm run build
npm start
```

构建后可直接在 http://localhost:8011 使用平台。生产访问前应自行配置部署、访问控制与项目存储；当前为单个浏览器的本地工作区，不包含账号与云端协作。

## 使用流程

1. 在组件管理中添加开发板、屏幕、键盘或按钮，替换初始占位尺寸。
2. 每个组件上传正面、背面、接口侧面与高度侧面照片。界面内提供各视角的拍摄要求。
3. 输入与轮廓对应的长宽；正面和背面可自动识别轮廓，也可标记 PCB 四角进行透视校准。自动识别的圆孔需要人工选择用途，孔径仍需实测。
4. 设置安装位置、组件最低点 Z、安装基准偏移、孔位和需要露出的侧面接口。屏幕／键盘开口可以在校准照片中框选，或直接输入。
5. 在 2D 中拖动组件，或输入精确坐标；查看 3D 装配和分解图。自动排布按底壳和面板两层保守排列。
6. 调整外壳尺寸、壁厚、装配间隙、支撑柱、螺丝导孔、定位边和通风孔。几何错误会阻止导出；未实测记录随试打印包一起保存。
7. 先打印安装孔薄板验证孔位，再试装底壳与上盖。

## Pi AI 预标注与对话调整

平台实际使用 `@earendil-works/pi-coding-agent@1.2.0` 的 SDK。Pi 负责工具调用与会话，图片理解和对话由你选定的模型供应商完成。首次启动未配置凭据时，界面明确显示“待配置凭据”，不会把 OpenCV 结果当作 AI 输出。

点击顶部或 AI 面板内的 **AI 设置**，选择 Anthropic、OpenAI、Google Gemini 或自定义兼容接口，填写模型与 API Key，再点击 **保存并启用**。保存立即生效，无需重启；可点击 **测试连接** 发起一次短文字请求。测试成功只表示文字调用可用，图片理解及工具调用能力需在实际任务中复核。

测试失败会显示上游 HTTP 状态、当前模型、协议及已识别的供应商错误码，不返回原始错误内容或请求密钥。401 通常表示认证失败，403 表示供应商拒绝请求，404 需检查接口或模型，429 需检查频率或额度；平台自身的 502 会与上游状态分别展示。模型出现在 `/models` 列表中不等于该 Key 有生成权限。

页面输入的密钥通过同源 API 保存到本机 `.pi-state/ai-settings.json`（目录权限 0700，文件权限 0600，已忽略提交）。这是本机文件保存，不是加密保险库。密钥不回传至页面，不写入 IndexedDB、项目 JSON 或 STL 打印包。保存后输入框清空；留空保留此供应商原密钥，各供应商凭据分别保存。更换接口地址必须重新输入密钥。保存配置会开始新的 Agent 会话；AI 请求进行中需停止或等完成后保存。

自定义接口填写 Base URL、模型 ID、协议及是否支持图片，支持 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages 和 Google Generative AI 协议。模型须支持工具调用，预标注还须支持图片。可接入本地 HTTP 模型端点；免鉴权端点的 API Key 可填 `local`。模型选择列表来自 Pi 注册表，保存自定义接口后立即加入列表。

仍支持服务端 `.env` 配置（复制 `.env.example`），以及 `ANTHROPIC_API_KEY`、`OPENAI_API_KEY`、`GEMINI_API_KEY` 等 Pi 原生环境变量；`PI_AUTH_FILE` 可指定已有 Pi 认证文件。页面保存的同供应商设置优先于环境配置；其他供应商不受影响。修改 `.env` 需重启服务并刷新页面，不要使用 `VITE_` 前缀存密钥。

- **图片与测量 → AI 预标注**：上传/校准后自动调用视觉模型（可关闭），也能手动重试。图片上的文字视为数据。返回板角、安装孔、显示/键盘开口、接口和遮挡候选，含编号、置信度及待复核事项。
- 原图中的框以归一化坐标展示；采用 AI 板角并经 OpenCV 校准后，再次预标注才能按已知长宽转换为毫米。只采用选中的候选，孔位追加并排除相距 1 mm 内的重复孔。可以编辑标注框、名称、孔坐标、孔径及开口位置，也能单独保存标注。背面孔位需核对正面坐标方向。
- 接口预标注可辅助填写板边、宽度和中心位置；高度及相对组件底面的 Z 需要补充。未填写完整时不生成接口开孔。标注估算不会自动成为“已复核”。
- **AI 设计助手**：例如“外壳加高 5 mm”“关闭通风孔”“屏幕往上移动 2 mm”。Pi 使用 `inspect_design`、`edit_design`、`auto_layout` 修改真实项目；没有 bash、文件或任意网络工具。每次修改先做几何检查和实体生成，通过后在对话结束时一次应用并更新预览，支持撤销。
- 流式显示回复和工具状态，支持停止及更换模型。停止、失败或期间发生新的设计修改时，不覆盖当前项目。单次请求限时 180 秒，对话最多调用 20 次工具。对话在服务端内存中保留 30 分钟，最多 30 个会话；页面刷新或新对话不恢复历史。

调用路径：浏览器 → FastAPI `/api/ai/*` → 本地 Node Pi 服务（8012）→ 所选模型供应商。Pi 设计工具回调现有 FastAPI 几何服务，STL 始终由确定性几何程序生成。图片预标注发送当前视角图片、输入长宽高及 CV 候选；设计对话发送参数，不发送原始照片。

官方接口核查及引用见 [Pi 接入依据](pi-integration.md)。

## 坐标与安装基准

全项目单位为毫米。俯视图原点为外壳左上角，X 向右、Y 向前（下）；Z 从外壳外底面向上。

组件 `width/depth/height` 是实际外形包围尺寸，`x/y/z` 是组件包围盒最低角。开发板总高应包含底部突出元件。底壳安装的 `mountOffset` 是最低点到 PCB 支撑面的高度，支撑柱顶面为 `z + mountOffset`。面板安装时，它是最高点向下到安装基准的距离，支撑面为 `z + height - mountOffset`；可视屏幕与键帽可经上盖开口突出，安装基准必须位于上盖下方。

接口 `offset` 是接口中心沿对应板边的距离；`z` 是接口开孔底边相对组件最低点的高度。接口必须靠近对应侧壁，板边到侧壁超过 3 mm 时会阻止导出。模型在输入开口尺寸外增加每侧装配间隙。

## 第一版边界

- OpenCV 负责轮廓校准与圆孔候选；可选的 Pi 视觉模型负责语义预标注。任何图片推断都不等于实测，单张照片无法可靠恢复不可见高度。
- 侧视照片作为测量参考；高度、安装基准、接口尺寸和插头空间由用户输入并复核。
- 仅支持沿 X/Y 方向安装的矩形组件、螺丝固定两片外壳；独立按钮生成圆形面板开孔，需使用螺母等实际固定方式。
- 屏幕／键盘固定柱以用户提供的安装孔生成；未提供安装孔时会明确提示尚无固定结构。
- 检查使用组件包围盒，不能替代连接器详细模型、PCB 元件分布、螺丝长度、排线及散热器的完整装配验证。
- STL 使用 Manifold 布尔实体生成，与 3D 预览共用同一几何。上盖导出时翻转为外表面朝下；未包含打印螺纹、卡扣及 STEP 导出。
- 项目及照片存储于当前浏览器 IndexedDB。OpenCV 上传仅在本地处理；启用 AI 预标注会发送当前视角图片给你选定的供应商。项目 JSON 包含照片与 AI 标注，可导出备份。
- 内置样例的开发板长宽来自用户尺寸图；孔位为图片估算，高度、接口、屏幕与键盘均为明确标记的示例值。

## 验证

```sh
npm run build
npm test
```

后端测试覆盖实图孔位识别、四角校准、空间碰撞、越界、接口可达性、面板突出、安装基准偏移、偏心开口、封闭网格及打印包内容。Agent 测试通过受控本地模型端点运行真实 Pi SDK，验证图片输入、工具循环、失败回滚、流式会话、最新项目上下文、中止，以及凭据即时生效、重启恢复、密钥保留、连接测试、错误脱敏和配置接口来源校验；它们不验证真实供应商的识别精度。

## 技术结构

- `src/`：React + TypeScript + Tailwind，Radix 对话框与标签页，Three.js 交互预览。
- `server/models.py`：输入模型与几何检查。
- `server/vision.py`：照片校准和孔位候选检测。
- `server/geometry.py`：底壳、上盖与孔位小样实体生成。
- `server/app.py`：FastAPI 图像、预览、检查与导出接口。
- `agent/pi.mjs`：Pi 模型、凭据、系统提示与受限会话。
- `agent/settings.mjs`：页面凭据校验、本机原子保存与公开配置摘要。
- `agent/domain.mjs`：领域工具、参数约束与标注换算。
- `agent/server.mjs`：图片预标注和流式对话 HTTP 服务。
- `src/components/AIAnnotator.tsx`、`AgentPanel.tsx`：预标注复核与对话工作台。
- `src/components/AISettings.tsx`：凭据设置与连接测试表单。
