# 壳研使用指南

面向矩形开发板、矩形屏幕、矩形键盘及圆形面板按钮的本地外壳设计平台。支持照片上传与透视校准、圆孔候选识别、组件布局、实体三维预览和 STL 打印包导出。

## 启动

需要 Node.js 22.19+、Python 3.11+。

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r server/requirements.txt
npm ci
npm run dev
```

打开 http://localhost:5176 。开发服务使用前端 5176、后端 8011 端口；Vite 代理 `/api`。

```sh
npm run setup:login
npm run build
npm start
```

构建后打开 http://localhost:5176 。管理员账户由 `setup:login` 配置，页面与业务接口需登录；Pi 仅监听本机。详情见 [局域网部署指南](lan-deployment.md)。项目仍保存在各浏览器，跨设备需导入/导出 JSON。

## 使用流程

1. 在组件管理中添加开发板、屏幕、键盘或按钮，替换初始占位尺寸。
2. 每个组件上传正面、背面、接口侧面与高度侧面照片。界面内提供各视角的拍摄要求。
3. 输入与轮廓对应的长宽；正面和背面可自动识别轮廓，也可标记 PCB 四角进行透视校准。自动识别的圆孔需要人工选择用途，孔径仍需实测。
4. 设置安装位置、组件最低点 Z、安装基准偏移、孔位和需要露出的侧面接口。屏幕／键盘开口可以在校准照片中框选，或直接输入；没有安装孔时可选择上盖粘贴承托台。
5. 在 2D 中拖动组件，或输入精确坐标；查看 3D 装配和分解图。自动排布按底壳和面板两层保守排列。
6. 调整外壳尺寸、四角圆角、壁厚、装配间隙、安装孔支撑柱或粘贴承托台、螺丝导孔、定位边和通风孔。几何错误会阻止导出；未实测记录随试打印包一起保存。
7. 先打印安装孔薄板验证孔位，再试装底壳与上盖。

## Pi AI 预标注与对话调整

平台实际使用 `@earendil-works/pi-coding-agent@1.2.0` 的 SDK。Pi 负责工具调用与会话，图片理解和对话由你选定的模型供应商完成。首次启动未配置凭据时，界面明确显示“待配置凭据”，不会把 OpenCV 结果当作 AI 输出。

点击顶部或 AI 面板内的 **AI 设置**，选择 Anthropic、OpenAI、Google Gemini 或自定义兼容接口，填写模型与 API Key，再点击 **保存并启用**。保存立即生效，无需重启；可点击 **测试连接** 发起一次短文字请求。测试成功只表示文字调用可用，图片理解及工具调用能力需在实际任务中复核。

测试失败会显示上游 HTTP 状态、当前模型、协议及已识别的供应商错误码，不返回原始错误内容或请求密钥。401 通常表示认证失败，403 表示供应商拒绝请求，404 需检查接口或模型，429 需检查频率或额度；平台自身的 502 会与上游状态分别展示。模型出现在 `/models` 列表中不等于该 Key 有生成权限。

页面输入的密钥通过同源 API 保存到本机 `.pi-state/ai-settings.json`（目录权限 0700，文件权限 0600，已忽略提交）。这是本机文件保存，不是加密保险库。密钥不回传至页面，不写入 IndexedDB、项目 JSON 或 STL 打印包。保存后输入框清空；留空保留此供应商原密钥，各供应商凭据分别保存。更换接口地址必须重新输入密钥。保存配置会开始新的 Agent 会话；AI 请求进行中需停止或等完成后保存。

自定义接口填写 Base URL、模型 ID、协议及是否支持图片，支持 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages 和 Google Generative AI 协议。模型须支持工具调用，预标注还须支持图片。可接入本地 HTTP 模型端点；免鉴权端点的 API Key 可填 `local`。模型选择列表来自 Pi 注册表，保存自定义接口后立即加入列表。

仍支持服务端 `.env` 配置（复制 `.env.example`），以及 `ANTHROPIC_API_KEY`、`OPENAI_API_KEY`、`GEMINI_API_KEY` 等 Pi 原生环境变量；`PI_AUTH_FILE` 可指定已有 Pi 认证文件。页面保存的同供应商设置优先于环境配置；其他供应商不受影响。修改 `.env` 需重启服务并刷新页面，不要使用 `VITE_` 前缀存密钥。

- **图片与测量 → 统一标注并生成 3D 模型**：上传和校准只更新图片，不触发 AI。补齐当前模组的照片后，点击按钮，将全部已上传视角一次发送给所选视觉模型。返回每张图片的板角、孔位、接口等候选，并生成可编辑的主体、孔和局部实体。完成后进入“模组管理”。
- 原图中的框以归一化坐标展示；采用 AI 板角并经 OpenCV 校准后，再次点击统一生成才能按已知长宽转换为毫米。只采用选中的候选，孔位追加并排除相距 1 mm 内的重复孔。可以编辑标注框、名称、孔坐标、孔径及开口位置，也能单独保存标注。背面孔位需核对正面坐标方向。
- 接口预标注可辅助填写板边、宽度和中心位置；高度及相对组件底面的 Z 需要补充。未填写完整时不生成接口开孔。标注估算不会自动成为“已复核”。
- **AI 设计助手**：例如“外壳加高 5 mm”“关闭通风孔”“屏幕往上移动 2 mm”。Pi 使用 `inspect_design`、`edit_design`、`auto_layout` 修改真实项目；没有 bash、文件或任意网络工具。每次修改先做几何检查和实体生成，通过后在对话结束时一次应用并更新预览，支持撤销。
- 流式显示回复和工具状态，支持停止及更换模型。停止、失败或期间发生新的设计修改时，不覆盖当前项目。单次请求限时 180 秒，对话最多调用 20 次工具。对话在服务端内存中保留 30 分钟，最多 30 个会话；页面刷新或新对话不恢复历史。

调用路径：浏览器 → FastAPI `/api/ai/*` → 本地 Node Pi 服务（8012）→ 所选模型供应商。Pi 设计工具回调现有 FastAPI 几何服务，STL 始终由确定性几何程序生成。统一建模发送当前模组的全部已上传图片、已知长宽高、孔位及校准状态；设计对话发送参数，不发送原始照片。

官方接口核查及引用见 [Pi 接入依据](pi-integration.md)。

## 坐标与安装基准

### 外壳四角圆角

在外壳参数中设置 **四角圆角半径 R**（项目字段 `enclosure.cornerRadius`），也可以对 Pi 说“外壳四角设为 R12，保留组件尺寸和位置”。参数控制沿 Z 方向的四个竖直圆角，真实改变底壳与上盖实体及导出的 STL。

R0 为直角，旧项目缺少该字段时按 R0 加载。最大半径为 `min(width, depth) / 2`，过大的导入或 Agent 参数会被拒绝。内腔半径自动设为 `max(0, R − wall)`，上盖定位边按壁厚与装配间隙继续内偏移；角部螺丝柱必要时内移，上盖螺孔与其对应，定位边为螺柱留出间隙。

几何检查会核对组件包围盒与支撑柱是否进入内腔圆弧，接口开孔必须位于侧壁的直线段。后侧通风孔只在剩余直壁生成；圆角占用孔位时显示提示。圆角修改不会自动把待复核尺寸标成实测。顶面/底面外边缘圆角、倒角和接缝倒角仍需在导出后的 CAD 中处理。

### 组件与接口

全项目单位为毫米。俯视图原点为外壳左上角，X 向右、Y 向前（下）；Z 从外壳外底面向上。

组件 `width/depth/height` 是实际外形包围尺寸，`x/y/z` 是组件包围盒最低角。开发板总高应包含底部突出元件。底壳安装的 `mountOffset` 是最低点到 PCB 支撑面的高度，支撑柱顶面为 `z + mountOffset`。面板安装时，它是最高点向下到安装基准的距离，支撑面为 `z + height - mountOffset`；可视屏幕与键帽可经上盖开口突出，安装基准必须位于上盖下方。

接口 `offset` 是接口中心沿对应板边的距离；`z` 是接口开孔底边相对组件最低点的高度。接口必须靠近对应侧壁，板边到侧壁超过 3 mm 时会阻止导出。模型在输入开口尺寸外增加每侧装配间隙。

## 第一版边界

- OpenCV 负责轮廓校准与圆孔候选；可选的 Pi 视觉模型负责语义预标注。任何图片推断都不等于实测，单张照片无法可靠恢复不可见高度。
- 侧视照片作为测量参考；高度、安装基准、接口尺寸和插头空间由用户输入并复核。
- 支持沿外壳坐标轴安装的矩形组件及侧壁面板组件、螺丝固定两片外壳；独立按钮生成圆形面板开孔，需使用螺母等实际固定方式。
- 屏幕／键盘可用用户提供的安装孔生成固定柱，也可在上盖开口周围生成连续粘贴承托台。承托宽度、承托高度和胶粘避让可单独调整；胶水厚度、底框接触面和长期粘接强度仍需实物复核。
- 检查使用组件包围盒，不能替代连接器详细模型、PCB 元件分布、螺丝长度、排线及散热器的完整装配验证。
- STL 使用 Manifold 布尔实体生成，与 3D 预览共用同一几何。上盖导出时翻转为外表面朝下；未包含打印螺纹、卡扣及 STEP 导出。
- 项目及照片存储于当前浏览器 IndexedDB。OpenCV 上传仅在本地处理；点击统一生成时，才会发送当前模组的全部已上传视角给你选定的供应商。项目 JSON 包含照片、AI 标注及可编辑模组模型，可导出备份。
- 内置样例的开发板长宽来自用户尺寸图；孔位为图片估算，高度、接口、屏幕与键盘均为明确标记的示例值。

## 多组件与侧壁安装

组件库现有九种类型；新增模板均是待实测占位。在组件属性的“安装在”选择底壳、上盖、前/后/左/右侧壁，界面自动转向外形并贴近所选面。全局尺寸和位置仍沿 X/Y/Z。局部孔位和开口偏移用 U/V：上盖沿 X/Y，前后侧沿 X/Z，左右侧沿 Y/Z，侧面 V 从组件底部向上。四个侧壁上的照片采用时自动翻转纵向坐标，背面横向仍须核对。

面板开口可选矩形、圆孔、圆角矩形；内部组件可不开孔，侧壁安装必须有开口。安装孔在内壁和安装基准之间生成侧向支撑柱。按钮、开关及旋钮无孔时，只生成开孔，须核对实物螺母或卡扣。电池/模块可选择底壳托架与独立压条，扬声器可开启防护网。

“螺丝与支撑柱”中可设置四角上盖螺丝头平底沉孔。深度 0 关闭，最大深度为上盖厚度减 0.6 mm，直径至少比通孔大 0.4 mm、最大 7.2 mm。当前不生成锥形沉头孔。

无孔屏幕或键盘选择“上盖内侧粘贴承托台”后，开口周围生成内侧承托环，外圈连接上盖。`supportWidth` 为环宽，`supportHeight` 为承托厚度，`adhesiveClearance` 为垂直胶层厚度。承托下表面 Z = 组件安装基准 + 胶层厚度，开口只按外壳装配间隙放大。组件边框内须保留至少 1.2 mm 连续接触宽度；支撑越界、碰撞、突出上盖或无有效胶粘面会阻止导出。请实测边框，模型不估算长期胶粘强度。

Pi 支持 `list_component_templates` 与 `add_component`，也可通过 `edit_design` 调整所有新增参数。尺寸未给出时会先询问；明确允许示例占位时可使用模板。自动排布优先处理底壳与上盖层，侧壁组件沿所选外壁随尺寸变化，干涉时仍需调整沿边位置和 Z。

固定结构和接线留空已纳入本阶段，造型与 CAD 导出仍见 [能力路线图](roadmap-v0.2.md)。


## 装配功能与试装

在右侧“固定与装配”选择安装孔支撑柱、内侧粘贴台、底壳托架或不生成固定结构。保留的孔位在固定关闭时不会生成柱。添加实测安装孔会自动选择孔位固定。

- **托架**：支持底壳电池、模块、开发板；四边导向、底部承托、两侧螺丝柱与独立压条，可选 1.2 × 8 mm 绑带槽。调整 Z 为承托底板留足厚度，压条与上盖/相邻结构保持间距。需要实际螺丝、绝缘与软垫。
- **M3 热熔孔**：底壳柱/托架支持 `heatsetM3`。默认孔径 4.2、深度 4 mm 仅为可调整试打值，不对应已认证供应商规格；按实物铜螺母调整。盲孔底至少 0.8 mm，柱壁至少 1.2 mm，M3 压条通孔独立使用 3.2 mm；组件安装孔也应至少 3.2 mm。
- **轻触键帽**：侧壁按钮/开关可生成导向筒与独立防脱键帽，包含直径、每侧间隙、行程、防脱肩及外露长度。安装基准对应实物触点。开关必须自行固定，并能提供回弹；先试打导向配合，切片检查侧向筒和肩部支撑。
- **扬声器格栅**：圆形声孔内生成连接面板的筋，调节筋宽、净间距及厚度。启用时本体会退到内壁之后并留装配间隙，避免网筋相交；仍需实测安装孔或其他固定方式。
- **保留区**：布局页面添加全局 X/Y/Z 区域，选择线缆弯曲、插头插拔或组件拆卸，可关联组件。关联区随组件平移、外壳锚定缩放和自动排布移动，删除组件时一起删除。区域不会挖空壳体；线缆/插拔按合盖状态检查，组件拆卸按已移除上盖、盖上组件及所属压条检查，其余结构仍须避让。

在“本地项目”导入 [完整装配样例](../server/assembly-example.json)，可以查看上述所有能力。样例尺寸、螺丝和铜螺母均待实测，不是可直接用于量产的设计。

打印包包括底壳、上盖、可选孔位小样、各独立压条/键帽、`assembly.json`、测量 CSV 与装配说明。上盖外表面朝下，其他件的朝向见包内说明。按“小样与局部配合 → 独立件 → 固定开关与模块 → 接线和电池压条 → 粘贴面板 → 合盖和插拔检查”逐步试装。

工作区加载期间不可编辑。恢复失败时不会回写示例覆盖原设计，可以重试、下载原始数据，或主动导入有效项目备份。正常使用时自动保存并支持撤销/重做；照片和项目 JSON 仍需定期备份。


## 多视角模组模型

1. 在“模组管理”选择一个组件，录入外形与总厚度。每个模组分别上传正面、背面、接口侧面和高度侧面；至少一张照片即可生成。上传和校准不会启动 AI。
2. 可先用实测长宽校准俯视图，再点击“统一标注并生成 3D 模型”。按钮处理当前模组的全部已上传照片。需要已配置、同时支持图片与工具调用的模型。
3. 生成结果通过确定性几何检查后，标注与模型一次保存，并进入“模组管理”。在图片页面可以逐视角复核和编辑标注；采用候选仍需手动确认。
4. 拖动模型旋转、滚轮缩放、右键平移。在模型编辑器中调整主体底面、厚度，添加或修改长方体/圆柱实体及切除范围。坐标使用局部 U/V/法向厚度，更换安装面仍使用同一组模型参数。右侧属性用于修改模组外形与孔位。
5. 参数先在草稿中预览。模型须在已知外形内、体积为正、封闭且连通；越界、悬空、切空或切断会显示错误并阻止保存。点击“保存模型修改”才写入项目；支持撤销/重做、刷新恢复、项目 JSON 备份和重新导入。
6. “下载模组 STL”导出当前有效模型；装配预览复用已保存的同一实体。外壳打印包的 `assembly.json` 保留模型参数，器件自身的参考模型可单独下载。
